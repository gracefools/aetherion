## 2. Keamanan dan anti-duplikasi

- Semua operasi (`equip`, `unequip`, `use`, `sell`, `buy`, `upgrade`, `destroy`) dijalankan server terhadap inventory milik pemain itu sendiri; `uid` dari pemain lain atau karangan ditolak dengan "Item not found".
- Jumlah (`qty`) yang tidak valid dibaca sebagai 1; gold dicek sebelum transaksi.
- Saat login, data tersimpan dibersihkan (`cleanInventory`): `uid` ganda dibuang (item tidak bisa ada dua kali), base tak dikenal dibuang, stack/upgrade/rarity/affix dijepit ke batas sah, equipment yang tidak sah untuk job/level dipindah ke tas.
- Sebuah item selalu berada di tepat satu tempat (tas atau slot), dan seluruh inventory disimpan dalam satu `UPDATE`, sehingga tidak ada keadaan setengah tersimpan.

## 3. Bug yang ditemukan dan diperbaiki saat pengujian

- Perintah inventory `null` membuat server melempar exception (ditemukan oleh unit test) → sekarang ditolak sebagai "Unknown inventory command".

## 6. Keterbatasan yang diketahui

- Senjata starter menambah ±20–25% ATK di level 1 dibanding M5, jadi monster awal mati lebih cepat. Belum ada penyeimbangan ulang menyeluruh.
- Belum ada trade antar pemain, bank/gudang, crafting, socket/gem, atau durability (durability memang tidak direncanakan).
- Loot langsung masuk tas; tidak ada item tergeletak di tanah. Jika tas penuh, item hilang (gold tetap masuk) dan pemain diberi tahu.
- Toko baru berupa area di plaza, belum ada NPC pedagang (M8).
- Set item, passive unik, dan pool loot boss baru masuk di M7.
- Ikon dan sprite tetap dibuat dari kode, bukan karya ilustrator.
- Docker tetap belum bisa diverifikasi di lingkungan ini.
