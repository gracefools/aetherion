# Aetherion Online — Milestone 16: World Map, Tutorial and Settings

Version **0.16.0-alpha**.

## 1. Honest summary

- **The world map, the tutorial, the settings (with key binding) and English/Indonesian interface text work end to end.** Shown by unit, integration (real database) and browser tests.
- **The interface is translated; game content is not yet.** Every piece of interface text is looked up by key, in English and Indonesian. Messages the server sends (refusals, system lines, announcements) are translated by the client from a message catalog. Names and descriptions of items, skills, monsters, places and quests, NPC lore pages and quest texts are still shown in English in both languages. The settings screen says so.
- **The Indonesian text was written by the assistant** and has not been read by a native speaker.
- **Not covered by automated tests:**
  - the full-screen button (headless browsers do not grant full screen);
  - the visual effect of the effects-quality setting, the closer camera, and walking as a toggle (the settings are saved and validated, and the code paths are simple, but no test watches them on screen);
  - travelling from the map (it uses the same request as the waystone keeper, which is tested).

## 2. What the player gets

| Where | What |
|---|---|
| **World map (M)** | The six regions west to east with their recommended levels, your region marked, party members counted per region, dungeons and world bosses flagged. Pick a region to see its map, drawn from the same tiles as the game: town, waystone, dungeon entrances with their level, hunting grounds (monster, level, camp size), elites, world bosses, roads to the next region, you, your party members, and your own markers. Each layer can be hidden. **Unexplored** regions (waystone not attuned and never visited) show only their name, level and description. **Travel** from the map when standing at a waystone. **Markers**: click "Add a marker", click the map, name it; up to 30, kept with your account |
| **Tutorial** | A small coach shows the next step. There are 12 steps: moving, attacking, skills, runes, inventory, equipment, accepting a quest, potions, parties, dungeons, auto hunting and Rune Scrolls. A step is done when you actually do it in the game. Skip a step, or skip the whole tutorial. **F1** opens every step to read again, resume, or start over. Key names in the text follow your own bindings |
| **Settings (O)** | **Audio**: master, music, effects and ambient volume; music, effects and mute switches (from M10). **Controls**: key binding. **Graphics**: effects quality, screen shake, damage numbers, other players' name plates. **Interface**: language, interface scale (80–150%), full screen. **Camera & movement**: closer camera, walk key as a toggle. Everything applies at once and is saved to the account |
| **Key binding** | 37 actions, two keys each. To rebind, click the key and press the new one; Escape cancels. A key already in use is never taken silently: the screen names the action using it and asks before moving it. Escape, F5, F9, F11 and F12 cannot be bound. "Restore default keys" asks first. Hotbars, hints, tooltips and the tutorial show the player's own keys |
| **Language** | English or Bahasa Indonesia, switched at once without reloading. A new account starts in Indonesian if the browser's language is Indonesian |

**Keyboard use:**
- Every control is a real button, field or list, reachable with Tab.
- Settings tabs also move with the left and right arrows.
- Rebinding works from the keyboard: focus the key, press Enter, then press the new key.

**How translation works:**
- **Interface text:** `t('bag.title')` or `t('common.gold', { n })`. `id.ts` is typed against `en.ts`, so a missing Indonesian key fails the type check.
- **Run-time messages:** the server keeps writing English, the wire language. The client's `tm()` matches each message against an English template in `messages.ts` (`'Requires level {a}'`) and shows the Indonesian template with the same values. A message quoted inside another, such as `Trade cancelled: {a}`, is translated too.
- **Unknown text** is shown unchanged and is never lost.
- **New messages:** a unit test scans the server and game-loop source for every message sent to players and fails if the catalog does not cover it. A new server message cannot ship untranslated.
- **Adding a language:** add `xx.ts` with every key of `en.ts`, an `xx` column in `messages.ts`, and the language code in `LANGUAGES`.

**Settings validation (server and client alike, `cleanGameSettings`):**
- Only known actions and valid key codes are kept, at most two per action, and no key twice. A conflict sent by a broken client is resolved by dropping the later use.
- Language, scale and quality come from fixed lists.
- Tutorial steps are checked against the list.
- Markers: at most 30, with ids and zones checked, coordinates clamped, and labels stripped of markup and cut to 24 characters.

## 4. Tests

| Suite | Result |
|---|---|
| Type check | 0 errors |
| Unit + integration (real PostgreSQL and Redis) | **170 / 170** (165 before) |
| Browser end-to-end (two players) | **passed**, with a new world map, settings and tutorial section |

New unit tests:
- **Key bindings:** the default layout has no conflicts; every action is on the settings screen once; conflicts are reported, not resolved; reserved keys are refused; stored conflicts are cleaned.
- **Settings document:** every field is validated, markers are cleaned and capped, and a full document fits the size limit.
- **Translations:** English and Indonesian have the same keys and the same placeholders, and no sentence was left in English. Every key the code builds from data exists (all actions, tutorial steps, map layers, categories, rarities, ranks...).
- **Run-time messages:** the source scan (over 250 messages) finds none without a translation; catalog translation works, including nested messages, and unknown text passes through unchanged.

New integration test: game settings are stored per account in PostgreSQL next to the audio section without disturbing it. Conflicting keys are cleaned, malformed requests are refused and leave the stored settings alone, and an oversized document is refused.

Browser (new section):
- **World map:** your region and position, the waystone, hunting grounds, an elite, roads, and a dungeon in another region; an unexplored region showing nothing but its level; a marker placed where clicked, saved, and hidden with its layer.
- **Key binding:** attack moved to Q, with the conflict with a rune spell shown first; Q then really starts an attack on the server; the binding is saved to the account; defaults restored.
- **Settings:** arrow keys move between tabs; the interface scale changes.
- **Indonesian:** the settings, buttons, hotbar and a command refusal in chat all switch to Indonesian, then back to English.
- **Tutorial:** steps already done in the session are ticked; a step can be read again; start over, skip and resume work; moving completes the first step.

Fixed while testing:
- **Escape** stopped closing panels when a checkbox had focus. This was caused by the new shortcut handling, and is fixed.
- **Two old timing-sensitive steps** in the browser test (the free swing, and target selection near wandering monsters) now clear the monsters around the player first.
- **Two mistakes in the new test itself** were corrected (a duplicate label, and a monster that died to the first hit).
