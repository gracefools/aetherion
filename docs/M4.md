# Aetherion Online — Laporan Milestone 4 (Rune Magic & Skills)

Status: **M4 selesai dan teruji** di atas stack M1 (penyimpangan stack ada di `docs/M1.md`; tidak berubah). M5–M9 belum dikerjakan.

## 1. Yang dibangun

| Area | Implementasi |
|---|---|
| Rune | 5 elemen, 12 mantra, persis seperti daftar di prompt. Tiap karakter punya 2 slot rune (Mage 3). Rune dipasang ke slot lewat panel (K), hanya di luar pertarungan |
| Progresi rune | Rune naik level dengan dipakai (10 EXP per cast, maksimum level 10). Tiap level +8% efek; level tertentu membuka mantra berikutnya |
| Skill job | Semua 38 skill aktif dari skill tree keenam job bisa dipakai. 5 node pasif mengubah stat server (Fortify, Rune Focus, Rune Mastery, Evasion, Blood Pact) |
| Poin skill | 1 poin per level. Server memeriksa level, prasyarat, rank maksimum, dan sisa poin. Tiap rank +12% efek. Reset gratis di luar pertarungan |
| Eksekusi | Seluruhnya di server: biaya mana/rage, cooldown per ability, global cooldown 0,5 detik, jangkauan, validasi target |
| Waktu cast | Meteor Strike, Healing Rain, Earthquake, Cataclysm, Resurrection. Bergerak atau kena stun membatalkan tanpa biaya |
| Bentuk efek | Target tunggal, percikan, kerucut, rantai (Chain Lightning), area di sekitar diri, area di titik sasaran |
| Field | Zona yang berdenyut (Sanctuary, Healing Rain, Tornado, Earthquake, Volley) dan jebakan yang menunggu korban (Snare Trap, Explosive Trap) |
| Pertahanan | Stone Shield (menyerap sampai kolamnya habis), Mana Shield (70% damage dibayar mana), Guard Stance, Last Stand (tidak bisa mati), Divine Aegis (kebal) |
| Lain-lain | Stealth dan Smoke Bomb, Taunt (menimpa threat), Charge/Shadow Step/Blink/Fleet Step, Hunter's Mark, Death Mark, Purify, Resurrection (bangkit di tempat dengan 40% HP) |
| Pasif level 25 | Keenam pasif berpemicu yang di M3 belum jalan sekarang aktif: Retribution, Overflow, Toxicology, Ambush, Guardian Spirit, Undying Fury |
| Status | 17 status baru (total 24), termasuk Burning, Rooted, Shocked, dan semua buff di atas |
| Persistensi | Rank skill dan slot/level/EXP rune tersimpan di PostgreSQL (migrasi 003). Data dibersihkan saat dimuat: rank berlebih atau rune palsu tidak dipercaya |
| Klien | Hotbar dengan sapuan cooldown, panel Skills dan Runes, cast bar, target sekutu (klik pemain), pesan penolakan, efek visual untuk tiap mantra |
| Tanpa energi | Mana dan cooldown adalah mekanik pertarungan; tidak ada batas bermain |

## 2. Hasil uji (dijalankan)

**Unit + integrasi: 61/61 lulus** (`npm test`), 14 di antaranya baru untuk M4:
- **Setiap ability dieksekusi** (50 ability): diterima server, biaya dibayar, cooldown mulai, event efek sampai ke pemakai dan pemain lain, dan efek gameplay-nya terjadi (damage, heal, status, pindah posisi, taunt, bangkit, pembersihan).
- Tabel: 12 mantra dengan nama persis, tiap mantra punya tampilan sendiri, tiap node aktif punya definisi.
- Poin skill, gerbang level, prasyarat, rank maksimum, reset, dan pembersihan data tersimpan.
- Penolakan: tidak dikenal, belum dipelajari, job lain, rune belum dipasang, level rune kurang, mana kurang, cooldown, GCD, mati, stun, di luar jangkauan, tanpa target.
- Progresi rune: level 5 = +32% damage, Elemental Surge +35%, jumlah cast untuk naik level sesuai rumus, Rune Focus menurunkan biaya.
- Bentuk area: percikan lebih lemah, kerucut tidak mengenai belakang, rantai mengenai tepat 4 target dengan damage menurun.
- Cast: tidak ada efek atau biaya sebelum selesai; bergerak dan stun membatalkan.
- Perisai, stealth, jebakan (sekali pakai, tidak terpicu monster terbang), zona (8 denyut Sanctuary tepat), keenam pasif level 25, skill gerak (tidak pernah berakhir di dalam tembok), Resurrection.
- Lewat jaringan nyata: 30 permintaan Fireball dalam 1,2 detik menghasilkan tepat 1 cast; build tersimpan dan dipulihkan; baris database yang dirusak dibersihkan saat login.

**Browser (Chromium headless): lulus tiga kali berturut-turut.** Mempelajari Arcane Bolt lewat panel, memasang Fire Rune, menekan 1 dan Q mengurangi HP target dan mana, pemain lain melihat animasi cast, klik hotbar saat cooldown memunculkan "Not ready".

**Uji beban** (60 detik, mesin 2 core, bot dan server di mesin yang sama; bot menyerang tiap detik dan memakai skill serta mantra tiap 2,5 detik):

| Klien | Tick rate | Tick avg | Tick p99 | Tick maks | Terlambat | Putus | Cast ability |
|---|---|---|---|---|---|---|---|
| 100 | 20 Hz | 3,5 ms | 9,0 ms | 21,5 ms | 0 | 0 | 367 |
| 250 (2 channel) | 20 Hz | 9,9 ms | 22,9 ms | 46,1 ms | 0 | 0 | 775 |

Tidak ada tick terlambat, tetapi pada 250 klien tick terlama (46 ms) sudah dekat anggaran 50 ms. Rata-rata dan p99 masih longgar. Ini perlu diperhatikan di M9; untuk saat ini kapasitas aman satu proses di mesin ini sekitar 150–200 pemain.

## 4. Keterbatasan yang diketahui

- **Sasaran area mengikuti target**, bukan kursor. Meteor, Tornado, dan Volley jatuh di posisi monster yang ditarget; jebakan dan Sanctuary di kaki pemakai. Belum ada bidikan bebas dengan mouse.
- **"Sekutu" berarti semua pemain di dekatnya.** Sistem party masuk M5; setelah itu buff dan heal area bisa dibatasi ke party.
- **Efek visual field hanya terlihat bila pemiliknya ada di layar** saat field dibuat atau terpicu. Pemain yang datang belakangan tidak melihat zona yang sudah ada (zona tetap bekerja).
- **Hotbar tetap**: skill job di 1–7 sesuai urutan tree, mantra per slot rune. Belum bisa diatur ulang.
- **Keseimbangan belum diuji pemain.** Angka biaya, cooldown, dan pengali ditetapkan lewat perhitungan; Mage dengan tiga rune kemungkinan terlalu kuat di level tinggi.
- **Rune dipakai semua job** dengan magic attack masing-masing, jadi lemah untuk Knight dan Berserker. Ini disengaja tetapi belum disetel.
- Efek visual digambar kode (bentuk piksel beranimasi), bukan animasi buatan tangan.
- Headroom server pada 250 klien menipis (lihat uji beban).
- Keterbatasan sebelumnya masih berlaku: tanpa loot, tanpa boss, 2 dari 6 region, tanpa pathfinding monster, protokol JSON, Docker belum diverifikasi.
