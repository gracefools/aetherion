# MMORPG UI/UX Standards

## Components to audit
Player HUD, HP/MP/EXP bars, boss bars, minimap, inventory, equipment, skill hotbar, quests, party, guild, chat, combat log, dungeon status, notifications, and settings.

## Visual standards
- Clear information hierarchy and readable typography.
- Consistent panel surfaces, borders, icon language, and spacing.
- Strong contrast for important values and interactive states.
- Responsive behavior at supported resolutions and aspect ratios.
- Consistent hover, focus, selected, disabled, cooldown, and alert states.
- Avoid excessive decoration, padding, or visual noise.

## Functional safeguards
Preserve existing interactions, shortcuts, localization, accessibility, and data bindings. Do not redesign a UI component without tracing its state, events, and dependencies.

## Acceptance checks
Test minimum and common viewport sizes, scaling, text overflow, localization, interaction states, and gameplay visibility.
